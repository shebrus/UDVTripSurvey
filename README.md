# UDVTripSurvey — «План поездки»

Учебное приложение-анкета для сбора пожеланий участников совместной поездки, разработанное на **C#** с использованием **.NET MAUI 10**.

## Возможности

- Ввод имени организатора и количества участников (от 1 до 30).
- Выбор формата поездки и бюджета на человека.
- Выбор предпочтительных занятий и необходимости трансфера.
- Указание даты выезда, длительности (от 1 до 14 дней) и комментария.
- Отображение сводки по заполненной анкете.
- Очистка формы.

Для просмотра результата необходимо заполнить имя организатора и допустимое количество участников. Остальные параметры необязательны.

> Приложение формирует сводку анкеты. Оно не бронирует поездки и не составляет автоматический маршрут.

## Технологии

- C#
- .NET 10
- .NET MAUI (XAML)

## Запуск на Windows

1. Установите .NET 10 SDK и компоненты .NET MAUI для Windows (например, через Visual Studio с рабочей нагрузкой **.NET Multi-platform App UI development**).
2. Откройте файл `UDVTripSurvey.csproj` в Visual Studio и выберите целевое устройство Windows Machine.
3. Запустите проект (F5).

Альтернативно, из папки с файлом `UDVTripSurvey.csproj`:

```powershell
dotnet build -f net10.0-windows10.0.19041.0
dotnet run -f net10.0-windows10.0.19041.0
```

## Структура проекта

- `MainPage.xaml` — интерфейс анкеты.
- `MainPage.xaml.cs` — обработка ввода, проверка обязательных полей, вывод результата и очистка.
- `App.xaml`, `App.xaml.cs`, `AppShell.xaml` — настройка приложения и его оболочки.
- `MauiProgram.cs` — настройка MAUI-приложения.
- `Resources/` — изображения, шрифты и стили.
- `Platforms/` — платформенные файлы.
